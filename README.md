# github-stats-dashboard

A dashboard that visualizes GitHub repository statistics

## Getting Started

### Prerequisites

- Python 3.10+

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/github-stats-dashboard.git
cd github-stats-dashboard
```

### Run

```bash
python main.py
```
